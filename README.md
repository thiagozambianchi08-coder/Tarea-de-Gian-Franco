## Las tres herramientas principales

Se complementan: juntas hacen que un sistema sea más claro, ordenado y fácil de mantener.

### 1. Diccionario de datos

Lista ordenada de todos los datos del sistema, explicando qué es cada uno. Evita errores y datos repetidos, y sirve como documentación.

![Diccionario de datos](capturas/diapositiva-04.png)

### 2. Diagrama de flujo

Representa un proceso paso a paso con símbolos unidos por flechas: óvalo (inicio/fin), rectángulo (proceso), rombo (decisión) y paralelogramo (entrada/salida).

![Diagrama de flujo](capturas/diapositiva-06.png)

### 3. Diagrama entidad-relación (DER)

Muestra cómo se organizan y conectan los datos: entidades, atributos, relaciones, claves primarias (PK) y cardinalidad (1:1, 1:N, N:M).

![Diagrama entidad-relación](capturas/diapositiva-08.png)

## Resumen del informe

**Parte I – 5.º año (enfoque estructurado: analizar y modelar)**
DFD, diagrama de control, diccionario de datos, lógica de procesos, diagrama de transición de estados, DER, prototipos, ciclo de vida, números aleatorios, teoría de modelos y documentación de usuario.

**Parte II – 7.º año (enfoque orientado a objetos: construir y documentar)**
POO (clases, objetos, herencia, `ArrayList`, ABM), DER, diagrama de clases UML, cursogramas, diagrama de flujo, casos de uso, documentación de proyectos, Git y GitHub, y planificación con PERT y Gantt.

## Conclusión

En 5.º año se aprende a **analizar y modelar**; en 7.º año, a **construir y documentar**. Los enfoques difieren, pero comparten un propósito: reducir la distancia entre lo que el usuario necesita y lo que el sistema hace.
